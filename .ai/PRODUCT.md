# Product

CALO-RPD Studio is a scientist-facing desktop environment for formulating, executing, comparing and validating robust reactive-power-dispatch studies. The active tree is development-only. It supports native Windows launch, CPU execution, CUDA-preferred acceleration, deterministic experiment provenance, publication-oriented results, and a separately governed TSH-CALO intelligence lifecycle.

The canonical scientist workflow is broadly: Dashboard -> CALO Intelligence -> Power System -> ORPD Formulation -> Algorithms -> Portfolio -> Robust Scenarios -> Experiment -> Results / Validation / Publication.

Do not reinterpret development status, historical release artifacts or prior policy age as scientific qualification evidence.
